# CSTR-SImulator

This project models a first-order reaction in a continuous stirred-tank reactor (CSTR). It calculates the steady-state outlet concentration, conversion, reaction rate, and residence time, and checks the steady-state mole balance. It also plots the startup response, compares conversion across flow rates, and simulates how concentration and accumulation respond to a sudden flow-rate change. The results show that increasing the flow rate reduces residence time and conversion, while the transient plots show the reactor approaching the new steady state after the change.

Run `python cstr_simulator.py` to enter operating conditions. The four plots are saved as PNG files in the `results` folder beside the script.
